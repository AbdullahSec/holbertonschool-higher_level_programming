# JavaScript Warm Up

This project covers the basics of JavaScript scripting with Node.js.

## Topics

- Variables and constants
- Command-line arguments with `process.argv`
- Conditions and loops
- Functions and recursion
- Arrays and objects
- Converting strings to integers

## Usage

Run a script with Node.js:

```bash
node 0-javascript_is_amazing.js
node 9-add.js 13 89
```

## Style Check

```bash
semistandard *.js
```

Each JavaScript file solves a separate task in the project.
