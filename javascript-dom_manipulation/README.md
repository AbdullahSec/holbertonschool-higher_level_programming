# JavaScript DOM Manipulation

This project contains JavaScript scripts for selecting and updating DOM elements, handling click events, changing classes and text, creating list items, and retrieving data with the Fetch API.

## Tasks

- 0-script.js changes the header text color to red.
- 1-script.js changes the header color when the red header control is clicked.
- 2-script.js adds the red class to the header on click.
- 3-script.js toggles the header between the red and green classes.
- 4-script.js appends a new list item when the add control is clicked.
- 5-script.js updates the header text when the update control is clicked.
- 6-script.js fetches and displays a Star Wars character name.
- 7-script.js fetches and displays Star Wars movie titles.
- 8-script.js fetches and displays the French greeting after the document is ready.

The scripts use modern JavaScript without var and update the page without reloading it.
